---
name: address-pr-review
description: GitHub Pull Request 上のレビューコメントを確認し対応する
---

GitHub 上の PR レビュー対応を行います。作業前にユーザーの判断が必要な事項をすべて確認し、それ以降はノンストップで対応を完了させます。手戻りを防ぐため、判断に迷う事項があればまとめてユーザーに判断を仰いでください。対応内容が複雑な場合は plan モードを用いるべきです。

## 機械的に判断して良い場合

- 解決済み (resolved) のコメントは対応しなくてよい
- typo は方針検討せず実装してよい
- ルールの無効化を伴わないスタイル修正
- スレッドで合意済みまたはログインユーザーが対応方針を示しているもの

## ユーザーの判断が必要な事項の一例

- 仕様にかかわる検討事項
- 設計判断を含むもの
- レビュワーの意図が読み切れないもの
- コミット方針 (新規コミット / fixup + autosquash)
- スタイル修正において、局所的なルールの無効化が望ましいと思われるもの

## Git 操作

- 新規コミットの場合、コミットメッセージに「レビュー対応」のような文言を使わない。メッセージの書き方やコミットの分割粒度は通常のコミットに準ずる。
- 修正コミットの場合、`--force-with-lease` で push する

## 完了条件

- 対応すると決めた問題をすべて修正している
- push 直前の状態で push 前・コミット時のチェック (test, lint, format etc.) が完了していること
- push まで完了していること

レビュアーへの返信、スレッドの resolve は明示指示がない限り行わなくてよい。
